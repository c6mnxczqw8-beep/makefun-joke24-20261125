# One-Line Office Joke: 24-Hour Sprint — entry

A program/v1 entry for the make.fun "One-Line Office Joke:
24-Hour Sprint" bounty. `main.py` writes one office joke to
`/output/entry.txt` (or to `$MAKEFUN_OUTPUT_DIR/entry.txt` when
that variable is set).

The joke:

> This meeting should have been an email, the email should have been a text, and the text should have been a thought nobody had.

The most universal complaint in office life, run down a ladder:
every step shrinks the message and raises the absurdity, until
the final clause reveals the message never needed to exist at
all. A refinement pass added the third rung ("a thought nobody
had") to the draft's two-step version, because that is where
the laugh lands. 126 characters. See `CANDIDATES.md` for the
full draft list this winner was picked from.
